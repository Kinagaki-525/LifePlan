# Contract: 入力画面の説明と結果表示

表示の要件は正本 `docs/simulator/index.md` 3.5、6.1、6.2、6.4。ここでは表示位置と ViewModel の対応を定める。

## 入力画面

| 位置 | 内容 | 出どころ |
| --- | --- | --- |
| 家族構成タブ・子ども年齢の下 | 子ども欄の説明 | `ExpenseGuidance.ChildNote` |
| ライフイベントタブ・住宅購入の下 | 住宅購入欄の説明（年1%） | `ExpenseGuidance.HousingNote` |
| 支出タブ・基本生活費の下 | 基本生活費の説明、子どもの概算月額（合計または年齢帯一覧）と注記 | `ExpenseGuidance.BasicLivingCostNote`、`ChildMonthlyReference*` |
| 支出タブ・その他支出の下 | その他支出の説明 | `ExpenseGuidance.OtherCostNote` |
| 支出タブ・カード下部（実行ボタンの上） | 物価上昇の説明（年2%） | `ExpenseGuidance.InflationNote` |
| フォーム上部（検証エラー枠の近く） | 旧版送信の案内 | `SpecVersionNotice` |

- いずれも折りたたまず常時表示。既存の `life-plan-help` を使い、スマートフォン幅で折り返す
- 入力行の中の説明は `life-plan-help--block` で入力欄の列から右端まで使い、ラベル列に回り込ませない
- 送信後の再表示でも、開始年に計上対象の子どもがいない（子どもなし・全員出生前・全員負担終了）場合は、送信前と同じ年齢帯ごとの一覧を表示する
- 想定インフレ率の入力欄は表示しない
