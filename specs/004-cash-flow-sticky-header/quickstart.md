# Quickstart: スマートフォン版キャッシュフロー表の年度ヘッダー固定の検証

**Feature**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md) | **Contract**: [contracts/cash-flow-table-ui.md](contracts/cash-flow-table-ui.md)

## 1. 準備

```bash
dotnet build LifePlan.slnx -m:1
dotnet test LifePlan.slnx -m:1
dotnet run --project LifePlan --urls http://localhost:5250
```

- 試算の入力：夫 30 歳・妻 26 歳、その他は初期値（年齢が空の年度を含む。2026 年に試算すると夫は 2097〜2100 年が空）。必要に応じて、妻が年上（夫 26 歳・妻 30 歳）、夫婦とも 16 歳（列が最多）、夫婦とも 95 歳（列が少ない）、子どもあり、でも確認する。
- 結果画面は POST で表示する。自動操作では入力画面で値を入れ、フォームを送信する（偽造防止トークンはフォームに含まれる）。
- **修正前の基準値**：`develop`（`cfb8f53`）をビルド・起動し、A5 の計測とスクリーンショットを先に記録しておく。

## 3. ブラウザの自動操作による確認（SC-012〜SC-017）

Playwright（Node.js）＋ Chromium の検証用スクリプトをスクラッチに置いて実行する（リポジトリに含めない。[research.md](research.md) R8）。

共通の設定：

- スマートフォン：`viewport` の幅 320 / 375 / 390 / 430px、高さ 700px、`isMobile: true`、`hasTouch: true`。
- PC：幅 1280px、高さ 800px。
- ページのスクロールは `scrollTo({ top, behavior: 'instant' })` で行う（Bootstrap の `scroll-behavior: smooth` のため。research.md R0）。
- 横位置：先頭（0）・中間（最大の半分）・末尾（最大）。縦位置：表の前・表の先頭付近（表の先頭 + 10px）・表の途中・表の終端付近（表の終端 − 見出しの高さ − 10px）・表の後（単位の注記、シミュレーショングラフ、前提条件がそれぞれ画面上端に来る 3 位置）。
- 計測はページの読み込みとフォントの読み込み（`document.fonts.ready`）の後に行う。
