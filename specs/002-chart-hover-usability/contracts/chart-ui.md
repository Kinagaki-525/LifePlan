# Contract: シミュレーショングラフの画面構成と操作

表示の要件は正本 `docs/simulator/index.md` v1.3 6.3。ここでは、結果画面のグラフ枠内の構成、文言、ARIA、操作を定める。状態と遷移は [data-model.md](../data-model.md)、年度選択欄の採用理由は [research.md](../research.md) R6。

## 構成（上から順）

| 順 | 要素 | 内容 | 変更 |
| --- | --- | --- | --- |
| 1 | 表示項目（`fieldset`） | 4つのチェックボックス。各ラベルは「色マーカー（`aria-hidden`）＋項目名」。初期状態はすべて選択 | 色マーカーを追加 |
| 2 | 操作案内（`p`） | PC向けとタッチ向けの2文。メディアクエリでどちらか一方だけ表示。グラフを表示できない環境では表示しない | 新規 |
| 3 | グラフ枠 | Canvas（折れ線・縦線・マーカー、`role="img"`、フォーカス対象外）とツールチップ | ツールチップを追加。Canvas の代替テキストを変更し、`tabindex` を外す |
| 4 | 年度選択欄 | ラベル「表示する年度」＋ `select`。PC・スマートフォンとも常に表示し、一覧からすべての年度を選べる | 新規 |
| 5 | 数値表示欄 | 固定中の年度の金額。`aria-live="polite"` | 見出しと文言・強弱を変更 |
| 6 | 単位の注記 | 「金額の単位は万円です。」 | 変更なし |
| — | 凡例 | — | **削除** |
| — | 代替表示 | グラフを表示できない環境向け | 変更なし |

## 文言

| 場所 | 文言 |
| --- | --- |
| 操作案内（PC向け） | カーソルを合わせて金額を確認・クリックで年度を固定（←/→キーでも年度を選択できます） |
| 操作案内（タッチ向け） | グラフをタップして年度を選択 |
| 年度選択欄のラベル | 表示する年度 |
| 年度選択欄の先頭の選択肢（未選択、選択不可） | 年度を選択 |
| 年度選択欄の各選択肢 | {年}年 |
| 数値表示欄の見出し | 「{年}年」＋ラベル「固定中」 |
| 数値表示欄（未選択） | 年度が選択されていません |
| 数値表示欄・ツールチップ（表示項目なし） | 表示項目が選択されていません。 |
| ツールチップの見出し | 「{年}年」＋ラベル「カーソル位置」 |
| 金額 | 「{金額}万円」（例：1,234,567.9万円、-123.5万円、0.0万円） |
| Canvas の `aria-label` | 収入、支出、貯蓄合計の年次推移グラフ。年度別の金額はグラフ下の表示する年度で選択して確認できます |

## 操作案内の出し分け

| 環境 | 判定（CSS） | 表示 |
| --- | --- | --- |
| マウスなどカーソルを合わせられる入力がある（タッチと両方使える端末を含む） | `(any-hover: hover) and (any-pointer: fine)` | PC向け |
| 上記以外（タッチが主） | 上記に一致しない | タッチ向け |

## 操作

| 操作 | 入力 | 結果 |
| --- | --- | --- |
| カーソルを合わせる | マウス（ボタンを押していない） | ホバー年度のツールチップと実線の縦線を表示。固定年度は変わらない |
| カーソルをツールチップ上へ動かす | マウス | 表示を続ける |
| ツールチップをクリック | マウス（左ボタン） | ツールチップに表示中の年度を固定（グラフのクリックと同じ反映）。透過中のツールチップでは、クリックはグラフに届き、カーソル位置の年度（＝表示中の年度）を固定する |
| カーソルをグラフ枠の外へ出す | マウス | ツールチップと実線の縦線を消す |
| Esc | キーボード | ツールチップと実線の縦線を消す。次にホバー年度が変わると再表示 |
| クリック・ドラッグ | マウス | 年度を固定（既存）。押している間はツールチップを出さない。年度選択欄の値も更新 |
| タップ・横に動かす | タッチ | 年度を固定（既存）。ツールチップは出さない。年度選択欄の値も更新 |
| 縦スクロール・ピンチ | タッチ | ページを操作。操作前の固定に戻す（既存） |
| Tab | キーボード | 表示項目チェックボックスの次に年度選択欄へ移る（年度選択欄は常に表示） |
| 一覧から年度を選ぶ | タッチ・マウス・キーボード・読み上げソフト | 選んだ年度を固定。グラフと数値表示欄が同期する |
| ←/→/Home/End | キーボード（年度選択欄にフォーカス） | 前・次・最初・最後の年度を固定。未選択時の←/→は最初の年度。↑/↓など、その他の操作はブラウザ標準 |
| 年度を選ぶ | 読み上げソフト（デスクトップ・スマートフォン） | 標準の選択操作で年度を固定。数値表示欄の更新が読み上げられる |

## 年度選択欄

| 項目 | 値 |
| --- | --- |
| 要素 | `label` ＋ `select`（Bootstrap の `form-select`）。包む要素は常に表示（`visually-hidden-focusable` は使わない）。狭い幅でもラベルと選択欄が見切れないよう、選択欄は伸縮（最大 14rem）させ、収まらなければ折り返す |
| 選択肢 | 先頭に「年度を選択」（`value=""`、`disabled`、初期選択）、続けて各年度。値は年度の位置（または年） |
| 同期 | `select` の変更で固定年度を更新。ポインター操作で固定したら `select` の値を更新（`change` を発火させない） |
| 未選択 | 初期状態のみ。選択後に未選択へ戻す操作は設けない |
| 表示 | PC・スマートフォンとも常に表示する（以前の「フォーカスしたときだけ表示」は撤回） |

## Canvas の ARIA

| 属性 | 値 |
| --- | --- |
| `role` | `img`（既存） |
| `tabindex` | なし（既存の `0` を削除） |
| `aria-label` | 上記「文言」の表のとおり |

## ツールチップ

- `role="tooltip"`。`aria-hidden` は付けない。
- 左クリックで表示中の年度を固定する。ツールチップ内の文字を選択している場合は固定しない。カーソルは `pointer` にする。フォーカスは受け取らない（キーボードでの同じ操作は年度選択欄で行う）。
- グラフ枠内に絶対配置し、枠からはみ出さない。位置はホバー年度が変わったときだけ決め直す。
- 置き方の基本は次のとおり（詳細は research.md R3）。
  - カーソルと反対側の半分に置き、縦線のすぐ横（右、収まらなければ左）に寄せる。
  - それでも、ホバー年度になる横の範囲（カーソルの高さ）と重なる場合は、同じ半分で、その範囲の外に置く。
  - 同じ半分に置く場合と、どの位置でも重なる場合は、`life-plan-chart__tooltip--passthrough` を付けてポインター操作を透過させる。
- 内容は数値表示欄と同じく、年度、表示中の項目の色マーカー・項目名・金額。
