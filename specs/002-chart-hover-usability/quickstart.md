# Quickstart: シミュレーショングラフの操作性改善の検証

画面構成と文言は [contracts/chart-ui.md](contracts/chart-ui.md)、状態遷移は [data-model.md](data-model.md) を参照する。

## 1. ビルドとテスト

```powershell
dotnet build LifePlan.slnx -m:1
dotnet test LifePlan.slnx -m:1
```

- 期待結果：ビルドは警告・エラーなし、既存テストはすべて合格する（C# は変更しないので、計算結果は変わらない：SC-009）。
- Visual Studio のデバッガーで実行中は DLL がロックされる。その場合は `--artifacts-path <一時フォルダ>` を付けて別の出力先で実行する。

## 2. アプリでの確認（PC）

アプリを起動し、`/LifePlan` で条件を入力して試算する。結果のグラフで次を確認する。

| # | 操作 | 期待結果 | 対応 |
| --- | --- | --- | --- |

| P2 | 2040年付近をクリックし、2050年付近へカーソルを動かす | 数値表示欄と破線の縦線は2040年（「固定中」）のまま。ツールチップは2050年 | FR-002、SC-001 |

## 5. 自動化した確認（Edge headless のハーネス）

001 と同じ方法で、実 CSS・JS を読み込んだ検証用 HTML を一時フォルダ（スクラッチ）に作り、合成 PointerEvent・KeyboardEvent を送って DOM とスクリーンショットを確認する。検証用 HTML はリポジトリに含めない。

- ホバー：`pointermove`（mouse、buttons=0）→ ツールチップの年度・金額。固定の数値表示欄が変わらない。
- 終了：グラフ枠の `pointerleave`、Esc → ツールチップが非表示。
- タッチ：`pointerdown`/`pointerup`（touch）→ ツールチップが出ない。固定される。
- 一致：同じ年度で、ツールチップ・数値表示欄の金額が一致し、キャッシュフロー表の値（3桁区切りを除く）と一致する（SC-008）。
- 幅：320 / 375 / 390 / 430 / 1280px でスクリーンショットを撮り、重なり・はみ出しがない。
- 2026-10-12 時点のシナリオ名（`?mode=` で指定）と内容：

  | シナリオ | 内容 |
  | --- | --- |
  | none | 初期状態（未選択の文言、年度選択欄の先頭項目、Canvas に tabindex がない、凡例なし、色マーカー、案内文） |
  | hover / hoverfixed / leave / esc / edges / buttons / series | ホバー |
  | touch / cancel / firstcancel / twofinger | タッチ |
  | keys | 年度選択欄 |
  | tipclick | ツールチップのクリックによる固定、ホバーだけでは変わらないこと、右クリック・Esc 後は固定しないこと、グラフのクリック・ドラッグの維持 |
  | round | 金額の書式 |
  | resize | 画面幅の変更 |
  | sweep | 5つの高さで横になぞる |
  | shot / shotedge / shotkey | スクリーンショット用 |

- `sweep2&years={年数}&big=1` の内容：
  - 最前面の要素にイベントを送り、左右両方向に横になぞる。
  - ツールチップに遮られた回数、ホバー年度の更新漏れ、クリックが届かない位置、縦に動いてツールチップへ乗れるか（1.4.13）、操作を透過させた回数を確認する。
  - 条件の組み合わせは research.md R3 を参照する。
- 合成イベントでは、`select` の標準のキー操作（↑/↓、文字入力による移動）は動かない。そのため、K2 の ↑/↓ と文字入力は手動で確認する。
