# Data Model: シミュレーショングラフの操作性改善

サーバー側のデータ（ViewModel・JSON）は変更しない。ここでは、グラフの画面上の状態と遷移を定める。

## 入力データ（既存・変更なし）

`LifePlanChartPointViewModel` の配列。View の `script#life-plan-chart-data` に JSON（camelCase）で埋め込まれる。

| 項目 | 型 | 内容 |
| --- | --- | --- |
| `year` | int | 年度 |
| `totalIncomeManYen` | decimal | 収入合計（万円） |
| `totalExpenseManYen` | decimal | 支出合計（万円） |
| `savingsBalanceWithoutReturnManYen` | decimal | 貯蓄合計（0%運用、万円） |
| `savingsBalanceWithReturnManYen` | decimal | 貯蓄合計（想定年利運用、万円） |

金額の表示は既存の書式を使う。円に戻して、万円の小数第1位へ0から遠い方向に四捨五入し、3桁区切りを付ける。

## 画面の状態

| 状態 | 型 | 初期値 | 内容 |
| --- | --- | --- | --- |
| 固定中の年度（`selectedIndex`） | 年度の位置 \| なし | なし | グラフのクリック・タップ・ドラッグ、ツールチップのクリック、年度選択欄（キー操作・選択）で決まる。既存（ツールチップのクリックは追加修正） |
| ホバー中の年度（`hoverIndex`） | 年度の位置 \| なし | なし | マウスのカーソル位置に最も近い年度。新規 |
| ホバーの抑止（`hoverDismissed`） | 真偽 | 偽 | Esc で真。ホバー年度が変わるか、カーソルがグラフ枠から出ると偽に戻る。新規 |
| 表示中の系列 | 系列の配列 | 4系列すべて | チェックボックスの状態。既存 |
| 描画領域（`plotArea`） | 座標 | なし | 最後に描画できたときのプロット領域。年度の位置計算に使う。既存 |

ツールチップを表示するのは、`hoverIndex` がありかつ `hoverDismissed` が偽のときだけ。

## 状態遷移

### 固定中の年度（既存の動作を維持）

| きっかけ | 遷移 |
| --- | --- |
| マウスの左ボタンを押す・押したまま動かす・離す | 位置に最も近い年度を固定 |
| ツールチップを左クリック（一時表示中） | ホバー中の年度を固定。ツールチップ内の文字を選択しているときは変わらない |
| タッチで離す・横に動かす | 位置に最も近い年度を固定 |
| タッチ操作の取り消し（縦スクロール・ピンチの開始） | 操作前の値（なしを含む）に戻す |
| ←/→/Home/End（年度選択欄にフォーカス） | 前・次・最初・最後の年度を固定。未選択時の←/→は最初の年度 |
| 年度選択欄で年度を選ぶ（読み上げソフトの操作を含む） | 選んだ年度を固定 |
| ホバー、Esc、チェックボックス変更、画面幅の変更 | 変わらない |

### ホバー中の年度（新規）

| きっかけ | 条件 | 遷移 |
| --- | --- | --- |
| グラフ上でのマウス移動 | `pointerType` がマウス、ボタンを押していない | 位置に最も近い年度。年度が変わったら `hoverDismissed` を偽に戻す |
| マウスのボタンを押す | — | なし（ドラッグ中は一時表示を出さない） |
| グラフ枠（ツールチップを含む）からカーソルが出る | — | なし。`hoverDismissed` を偽に戻す |
| Esc キー | ツールチップを表示中 | `hoverDismissed` を真（年度は保持し、表示だけ止める） |
| タッチ・ペンの操作 | — | 変わらない（ツールチップは出ない） |
| 画面幅の変更 | — | なし（位置がずれたツールチップを残さない） |
| チェックボックスの変更 | ツールチップを表示中 | 年度は保持し、内容を新しい表示項目で更新する |

## 表示への対応

| 状態 | Canvas | ツールチップ | 数値表示欄 | 年度選択欄 |
| --- | --- | --- | --- | --- |
| 固定なし・ホバーなし | 折れ線のみ | 非表示 | 「年度が選択されていません」 | 「年度を選択」（選択不可の先頭項目） |
| 固定あり | 破線の縦線＋白抜きマーカー | — | 「固定中」＋年度＋金額 | 固定年度 |
| ホバーあり（抑止なし） | 実線の細い縦線＋塗りマーカー（固定より下に描く） | 「カーソル位置」＋年度＋金額 | 変化なし | 変化なし |
| 表示項目なし | 軸のみ | 年度＋「表示項目が選択されていません。」 | 年度＋「表示項目が選択されていません。」 | 変化なし |
