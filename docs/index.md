# ドキュメント索引

このフォルダは、機能ごとの仕様・実装方針を管理する。

## 構成

| フォルダ | 内容 |
| --- | --- |
| `simulator/` | ライフプランシミュレーター機能の仕様・実装方針 |
| `articles/` | microCMS を利用した記事表示機能の仕様・実装方針・記事作成ガイド |
| `common/` | 複数機能で参照する共通ガイドライン |
