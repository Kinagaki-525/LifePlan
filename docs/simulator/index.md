# ライフプランシミュレーター仕様書（統合版）

## 0. 位置づけ

本書はライフプランシミュレーターの実装基準仕様（v1.2）とする。実装時は本書を正とし、未確定事項は `docs/simulator/specs/open-issues.md` で管理する。

v1.2 の変更点：子どもの生活費と住宅維持費の自動計上、物価上昇率の固定化とインフレ率入力の撤去、結果の内訳と前提表示の追加。

## 1. 概要

`LifePlan` の ASP.NET Core MVC アプリに、家計の将来推移を可視化するライフプランシミュレーターを追加する。

- 対象：`Home/Index` の TOP ページと `LifePlan/Index` のシミュレーター画面
- 利用前提：夫婦での利用。単身利用は対象外
- 単位：入力は万円、内部計算は円、表示は万円
- 出力：キャッシュフロー表、シミュレーショングラフ
- 期間：現在年から夫・妻の両方が100歳に到達する年まで
- 対象外：保存、共有URL、PDF出力、メール登録、課金

> 旧仕様は90歳までだったが、`docs/simulator/web-app-spec.md` の詳細表が100歳前提のため、本書では夫・妻それぞれ100歳を終端とする。

## 2. 画面構成

TOP ページにはライフプランシミュレーターへの遷移ボタンを表示する。シミュレーター画面では、入力エリアを家族構成、ライフイベント、収入、貯蓄、支出、シミュレーション実行ボタンの順で表示する。試算後は既存タブ領域内の下部に、キャッシュフロー表、シミュレーショングラフの順で結果を表示する。

## 3. 入力仕様

### 3.1 家族構成

- 夫年齢、妻年齢：必須、16〜100の整数。両方入力されていない場合は試算不可
- 子ども1〜4年齢：任意、-20〜30の整数または `-（なし）`
- 子どもの負数年齢は将来出生予定として扱う（例：-3 は3年後出生）

### 3.2 ライフイベント

- 結婚：費用、実施年齢（夫年齢基準）
- 住宅購入：頭金、借入額、購入時期、ローン年数、想定金利
  - 住宅購入費（諸費用含む）は `頭金 + 借入額`
  - 購入時期未入力時は、頭金・借入額・ローン年数・想定金利を入力不可
  - 想定金利は年利%入力とし、0%以上、小数第1位まで入力可
- 自動車：購入額、初回購入年齢、買い替え間隔
- 教育費：第1〜4子ごとに、保育園〜大学院の区分を選択
  - 在籍期間は、保育園（0〜2歳）、幼稚園・保育園（3〜5歳）、小学校（6〜11歳）、中学校（12〜14歳）、高校（15〜17歳）、大学（18〜21歳）、大学院（22〜23歳）
  - 留年・浪人は考慮しない
- 旅行・その他：年間費用、開始年齢、終了年齢

### 3.3 貯蓄・収入・支出

- 貯蓄：現在の金融資産残高、想定運用年利（0〜20%）
- 収入：夫・妻それぞれ、職業、年収（手取り）、年収変化、就労開始/終了年齢、退職金、年金年額、年金受取開始年齢
  - 年収変化は `-（なし）`、`控えめ（年1%増）`、`標準（年2%増）` から選択
- 支出：毎月の基本生活費、毎月の家賃、その他支出（年間）
  - 基本生活費は、子どもの生活費（自動計上）を除いた世帯の月額とする。家賃・教育費は含めない
  - その他支出は、自動計上する子どもの生活費・住宅維持費や、他の欄で入力した支出を除いた年額とする
  - 物価上昇率・子どもの生活費・住宅維持費・独立年齢の入力欄は設けない（4.3、5.3 参照）
- 収入はすべて手取り前提とし、税・社会保険料は計算しない
- 年金の参考値は、厚生年金＋国民年金、国民年金のみの男女別水準を基準とする

### 3.4 入力方式とバリデーション

- 年齢、期間、区分、職業など選択肢が決まっている項目はプルダウンを基本とする
- 年齢、期間、金額、年収、退職金、年金、家賃、生活費などは半角整数入力を基本とする
- 金額、年収、退職金、年金、家賃、生活費などは0以上を基本とし、小数は許可しない
- 自由入力する利率は数値入力、単位は `%` とする。住宅ローンの想定金利は小数第1位まで入力可
- 年収変化は定義済みの選択肢のみ許可し、自由入力は行わない
- 結婚年齢は過去・現在・未来のいずれも入力可。夫の現在年齢以上には制限しない
- 就労終了年齢は就労開始年齢以上、年金受取開始年齢は就労終了年齢より後とする
- 旅行・その他の終了年齢は開始年齢以上とする
- 自動車の初回購入年齢が未入力の場合、買い替え間隔は無効扱いとする
- 子ども年齢が `-（なし）` の場合、その子どもの教育費入力は無効扱いとする
- 入力フォームは計算仕様バージョンを持つ。バージョンが欠落した送信は試算せず、入力を保持して画面へ戻し、費用範囲の説明を表示する。値の推測変換はしない
- 未定義の計算仕様バージョンは検証エラーとし、入力を保持する
- 旧画面の想定インフレ率など、計算に使わない値が送信されても計算に使わない

### 3.5 入力欄の説明

自動計上する費用の範囲を、各入力欄の近くに常時表示する（折りたたまない）。スマートフォン幅でも読める位置に置く。文言は画面幅に合わせて短縮してよいが、費用範囲を曖昧にしない。

| 場所 | 説明の趣旨 |
| --- | --- |
| 基本生活費 | 子どもの食費・衣服・日用品は自動計算するため、それを除いた月額を入力する。家賃・教育費は別に計算する |
| 子ども欄 | 年齢に応じた生活費を自動で加算する。教育費は選んだ進路から別に計算する |
| 住宅購入欄 | 購入費用の年1%を、税金・保険・修繕などの維持費として自動で加算する |
| その他支出 | 他の欄に入力していない支出を入力する。自動計算する子どもの生活費・住宅維持費は含めない |
| 支出欄または実行ボタン付近 | 生活費・教育費などは物価が年2%上がる仮定で計算する。住宅ローンなどは対象外 |

- 年2%は長期試算の仮定であり、確実な予測や最新の実績値と表現しない
- 基本生活費の付近に、子どもの生活費の参考月額を表示する。実際の内訳とは一致しない旨を添える。確認操作・追加入力・入力値の自動上書きはしない
  - 送信前（初期表示）：年齢帯ごとの1人あたり月換算額の一覧
  - 送信後の再表示（試算結果・検証エラー・旧版案内）：送信された子ども年齢による開始年の概算月額合計
  - 送信後でも、開始年に計上対象の子どもがいない場合（子どもなし・全員出生前・全員負担終了）は、送信前と同じ年齢帯ごとの一覧を表示する
  - 参考月額はサーバー側で求める。画面上で子ども年齢を変えても、送信するまで合計は更新しない

## 4. 計算仕様

### 4.1 試算期間と年齢

- 開始年は実行時の現在年、終了年は夫・妻の両方が100歳に到達する年
- 年次単位で計算し、内部で必要な場合は月次按分を利用する
- 夫・妻・子どもの年齢は初年度入力値を基準に毎年+1する
- 夫・妻はそれぞれ100歳を終端とし、100歳到達翌年以降は空白にする
- 子どもの初年度が空なら当該行は非表示。負数年齢は表では非表示、内部判定では使用可

### 4.2 収入

- 給与：就労開始〜終了年齢に計上し、設定した年率で毎年増減
- 退職金：就労終了年齢年に単発計上
- 年金：受給開始年齢以降に毎年計上
- 収入合計：夫・妻の給与、退職金、年金を合算
- 給与・退職金・年金は手取り金額として扱う

### 4.3 支出

- 基本生活費：`月額 × 12 × 物価係数`
- 子どもの生活費：子どもごとに5.3の年額を計上し、合算する（下記）
- 家賃：住宅購入年から0。物価係数は適用しない
- その他支出：`年額 × 物価係数`
- 結婚：指定年齢に単発計上。物価係数は適用しない
- 自動車：初回購入年齢から買い替え間隔ごとに単発計上。物価係数は適用しない
- 教育費：学校区分マスタに応じて対象年齢で計上し、物価係数を適用する
- 旅行・その他：開始〜終了年齢で毎年計上し、物価係数を適用する
- 住宅維持費：住宅購入年以降に計上する（下記）
- 支出合計：上記項目を一度ずつ合算。同一年に複数支出が重なる場合もそのまま合算

#### 物価上昇

- 物価上昇率は年2%で固定し、利用者は変更できない。日本銀行の物価安定目標を参照した長期試算の仮定であり、実績値や将来予測ではない
- 前提値はサーバー側で一元管理し、前提バージョンを持つ。送信された値は使わない
- 物価係数：`1.02^t`（`t = 計算年 − 開始年`、初年度 `t = 0`）
- 入力金額と教育費マスタは開始年の価格として扱う。初年度は増額せず、翌年から複利で適用する
- 適用対象：基本生活費、子どもの生活費、その他支出、教育費、旅行・その他、住宅維持費
- 適用対象外：家賃、頭金、住宅ローン返済、自動車、結婚
- 給与の年収変化とは連動させない

#### 子どもの生活費

- 第1〜4子それぞれについて、計算年の年齢が0歳以上かつ負担終了年齢未満の年に計上する。出生前と負担終了後は0
- 負担終了年齢は22歳。教育費で大学院を選択した子は24歳
- 年額：`5.3の基準年額 × 1.02^(計算年 − 2024)`。基準年額が2024年価格のため、開始年までの補正も同じ年2%で行う。開始年の物価係数を重ねて掛けない
- 例：2026年に0歳なら `590,000 × 1.02^2 = 613,836円`、翌2027年に1歳なら `626,113円`
- 子どもごとに円単位で四捨五入してから合算する
- 年額を計算の正本とし、月換算額を12倍して計算しない
- 入力した基本生活費から子どもの生活費を控除しない

#### 住宅維持費

- 住宅購入時期があり、`頭金 + 借入額` が正の場合に、購入年から試算終了年まで計上する。ローン完済後も継続する
- 年額：`(頭金 + 借入額) × 1% × 物価係数`。購入年も年額で計上し、月割りしない
- 固定資産税等・保険料・管理費・修繕積立金または修繕費の年平均をまとめた簡易的な仮置き。金融庁ライフプランシミュレーターの方式を参考にしたもので、実測平均や税率ではない
- 購入前と住宅購入なしの場合は0
- 購入時期があり `頭金 + 借入額` が0の場合は0とし、試算は止めずに未算定の案内を結果に表示する（6.4）
- 購入時期が現在より前で購入費用が入力されている場合は、現在年から計上する。現在の残債を購入価格と見なさない

#### 住宅ローン

- 購入年に頭金を一括計上する
- 借入額は直接支出にせず、借入額を元本にした年額ローン返済額を計上する
- 購入年は頭金と年額ローン返済額、次年度以降は年額ローン返済額のみを計上する
- 年額ローン返済額は、借入額を元本、想定金利を年利、ローン年数を返済年数とした元利均等返済で算出する
- 年利0%の場合は `借入額 ÷ ローン年数` を年額ローン返済額とする
- ローン年数は返済を計上する総年数とし、購入年を1年目として数える
- 例：購入年齢30歳、ローン年数35年の場合、30歳年から64歳年まで35年分を計上する

#### 教育費

初年度と次年度以降の金額が異なる区分は、各在籍期間の初年度のみ初年度金額を適用し、2年目以降は次年度以降金額を適用する。

### 4.4 貯蓄

- 初年度の開始金融資産は、現在の金融資産残高とする
- 収支差額：`収入合計 - 支出合計`
- 貯蓄合計（0%運用）：`前年末残高 + 当年収支差額`
- 貯蓄合計（想定年利運用）：`前年末残高に想定運用年利を適用 + 当年収支差額`
- 想定運用年利は、現在の金融資産残高を起点とする資産全体に適用する

### 4.5 端数処理

- 内部計算は円単位で行う
- 年額ローン返済額など、計算結果に小数が出る場合は円単位で四捨五入する
- 画面表示時は万円単位に換算する
- 物価係数を適用する費目は、各費目の年額を円単位で四捨五入する

## 6. 表示仕様

### 6.1 結果表示の構成

- 結果表示は、初年度サマリ、自動計上費用と前提、キャッシュフロー表、シミュレーショングラフで構成する
- 家計の実態との一致や、資金計画の安全を断定する表示はしない
- 結果は試算成功後に表示し、初期表示時と検証エラー時は表示しない
- 結果エリアは入力フォームと同じページ内、かつ既存タブ領域内の下部に表示する
- 結果表示時の入力タブはグレー表示とし、押下すると該当入力フォームへ戻れるようにする
- 入力フォームへ戻った後は、選択中の入力タブのみ有効色で表示する
- 検証エラー表示時は、エラーメッセージ枠と入力タブが接しないように適切な余白を設ける
- 結果エリアの下部に、条件を変更して再シミュレーションできる導線を配置する

### 6.2 キャッシュフロー表

- 家族年齢：夫、妻、子ども
- 収入系：給与、退職金、年金、合計
- 支出系：生活費、子どもの生活費、家賃、住宅維持費、イベント群、合計
- 生活費は入力した基本生活費（物価係数適用後）をそのまま表示し、控除行は設けない
- 貯蓄系：開始資産、収支差額、残高推移
- 表は Figma のキャッシュフロー表デザインに沿った緑枠フレーム内に表示し、列数が多い場合はページ全体ではなく表の枠内で横スクロールできるようにする
- 年次の列は横方向に並べ、行見出しと数値を比較しやすい表示にする
- 区分ごとに淡い背景色を分け、濃い色は避けて可読性を優先する
- 表示単位は万円とする

### 6.3 シミュレーショングラフ

- `wwwroot/js/life-plan-chart.js` で、収入合計、支出合計、貯蓄合計（想定運用年利を含む）を描画する
- グラフは専用の枠内に表示する
- グラフ未実装の段階では、専用枠内に Coming soon を表示する
- 凡例はグラフ枠内に表示し、貯蓄、収入、支出の系列を判別できるようにする
- 外部グラフライブラリは初期要件に含めず、表現力や保守性の必要が明確になった時点で検討する

### 6.4 初年度サマリと自動計上費用

- 結果の上部に、初年度の収入合計・支出合計・年間収支を表示する
- その下に、子どもの生活費と住宅維持費の初年度額を表示する。初年度が0で将来始まる費用は、開始年と開始年の概算額を表示する
- 住宅購入時期があり住宅価格が0の場合は「住宅価格が未設定のため維持費を含めていません」と表示する
- 前提として次を表示する。確認操作は求めない
  - 子どもの生活費の対象費目（衣類・食費・生活用品）と負担終了年齢（22歳、大学院選択時24歳）
  - 18歳以降は高校生の額を継続する仮定であること
  - 住宅維持費は購入費用の年1%であること
  - 対象支出に物価上昇年2%を適用し、家賃・住宅ローン等は対象外であること
  - 自動計上しない費用（子どもの携帯料金・小遣い・医療費、大学の下宿費など）
  - 「生活費と教育費の一部費目には重複が残る概算です」
