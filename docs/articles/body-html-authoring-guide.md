# 記事本文HTMLの入力ルール

microCMS の `body` はリッチエディタで作成した HTML を API から受け取り、アプリ側でサニタイズして表示する。
HTMLタグを文字列として貼り付ける運用は避ける。

## 基本方針

- 見出しは太字・下線の段落ではなく、リッチエディタの見出し（`h2`, `h3`）を使う。
- 通常の本文は段落（`p`）として入力する。
- 箇条書きは改行だけで並べず、リッチエディタのリスト（`ul` / `ol` / `li`）を使う。
- 記事内リンクは、本文中にURL文字列を貼るのではなく、リッチエディタのリンク機能で作成する。
- コード例を見せたい場合だけコードブロックを使う。CTAや通常リンクを表示したい目的でHTMLをコードブロックに入れない。

## CTAリンク

本文中にCTAボタンを置く場合は、リンク要素に `class="btn-primary"` を付ける。

```html
<a href="https://futari-kakei.com/simulation" class="btn-primary">
  ライフプランシミュレーションを無料で試す
</a>
```

既存記事に `&lt;a ...&gt;` のようなエスケープ済みリンクが段落単体で入っている場合は、初期互換としてアプリ側でリンクへ正規化する。
今後の記事では、リッチエディタのリンク機能で実HTMLとして入力することを正とする。

## アフィリエイトリンク

- 発行されたURL全体を `href` に設定する。
- URLを分解・推測・再構成しない。
- 必要に応じて `rel="sponsored nofollow noopener noreferrer"` を付ける。
- 新規タブで開く場合は `target="_blank"` と `rel="noopener noreferrer"` をセットで付ける。

## 画像

- サムネイルは横長画像を推奨する。
- 本文中の画像も、表示用途に合うサイズへ調整した画像を使う。
- 縦長画像や比率の異なる画像でも、アプリ側では画像全体が見えるように表示する。
