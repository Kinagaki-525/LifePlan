# 記事表示機能 未決事項

実装前に確認が必要な事項を管理する。

## 要相談

| 項目 | 論点 | 初期案 |
| --- | --- | --- |
| 詳細URL | `/Articles/{id}` でよいか、SEO向け slug を作るか | 初期実装は microCMS の `id` を利用 |
| 本文HTML | `Html.Raw` 信頼前提か、HTMLサニタイズを導入するか | 初期実装は編集者限定の信頼前提 |
| ナビゲーション | ヘッダー・フッターに記事リンクを出すか | `_Layout.cshtml` の既存コメントアウト導線を活用 |
| カテゴリフィルタURL | ピル型ボタン押下時のURL形式をどうするか | 推奨は `/Articles?category=household-budget&page=2` |
| カテゴリ一覧 | 右サイドバーのカテゴリクリック時の挙動 | カテゴリフィルタと同じ挙動にする案 |
| カテゴリ件数 | 全記事のカテゴリ件数か、現在取得中の記事内の件数か | 要相談 |
| タグ | `tags` を文字列のまま扱うか、microCMS側で配列型にするか | 初期実装はカンマ区切り文字列を分割 |
| エラー時表示 | 一覧・詳細で同じ文言にするか | 詳細は404相当、一覧は読み込み失敗表示 |
| キャッシュ | API呼び出しごとに取得するか、キャッシュするか | 初期実装ではキャッシュなし |
| OGP | 記事ごとのOGP metaを出すか | 初期実装では title / description 優先 |

## 質問票

| 項目 | 質問 |
| --- | --- |
| 記事詳細サイドバー | 記事詳細ページにも、一覧ページと同じCTA・新着記事・カテゴリを表示するか |
| サムネイル未設定時 | サムネイル未設定時は、スクリーンショットのような薄緑のプレースホルダー表示でよいか |

## 決定済み

- microCMS へのアクセスはサーバー側で行う。
- APIキーは環境変数または User Secrets で管理する。
- ブラウザ側 JavaScript に APIキーを渡さない。
- 記事一覧は1ページ6件表示とする。
- 右サイドバーCTAのリンク先は `/LifePlan`、ボタン文言は「無料でシミュレーション」とする。
- 新着記事は3件表示とする。
- モバイル表示では、サイドバーを記事一覧の下に縦積みする。
